# Эксперимент: embroidered-hero

**Идея:** «Шитьё по канве» — первый экран главной как плакат. Птица из `assets/hero.svg` собрана из семи ступенчатых ортогональных контуров, как вышивка или орнамент по сетке; ромб списка hero — тот же знак в малом. Птица стоит крупно в правой половине и уходит под нижний край экрана, заголовок и список — подпись к ней, кнопка «Расскажите о задаче» на месте. При загрузке птицу один раз «вышивают»: пунктир-стежок проходит по контурам снизу вверх (цоколь → нога → корпус → крылья → голова → звезда последней), каждая часть заливается белым, как только её контур прошит, под птицей на время шитья видна канва (клетка с шагом модуля птицы, белым 6 %), потом гаснет. Всё ≤1,4 с, дальше экран неподвижен. Ступенчатый стежок переходит в систему: маркеры-ромбы списка прошиваются той же иглой, фокус-кольцо кнопок, ссылок и полей формы — пунктирный «стежок» вместо сплошной обводки.
**Источник:** crazy (Безумец).
**Цель:** проверить, может ли первый экран быть статным плакатом с одним осмысленным жестом «мануфактуры» (вышивка знака) вместо декоративного движения.

## План
1. Hero → плакат: `min-height: 100svh`, текст слева (заголовок сверху, список и кнопка внизу), птица справа абсолютом, обрез 7 % снизу (цоколь уходит за край).
2. Птица инлайн в разметке: слой заливки (7 путей), слой стежков (те же пути, `stroke-dasharray: 9 6`) под маской-иглой (те же пути с `pathLength="1"`, `stroke-dashoffset 1 → 0`), канва — SVG pattern 31,32 ед. (шаг ступеней птицы).
3. Только CSS, без JS: стартовое состояние живёт лишь в `@keyframes`, статическое — готовая птица. `prefers-reduced-motion: reduce` и движки без анимаций — сразу готовая птица.
4. Маркеры списка: тот же контур прошивается и заливается (с задержками сверху вниз, укладываются в те же 1,4 с).
5. Фокус: `:focus-visible` — `outline: 2px dashed`, акцент на светлом, белый в hero и футере; поле формы — пунктир внутри плашки вместо `box-shadow`.
6. ≤959px: птица под текстом, прижата вправо, 78vw (≤480px), видно верхние 80 % — звезда, голова, крылья; обрез по низу hero.

## Что проверять
- Читается ли шитьё как ремесло (стежок по канве), а не аттракцион; не дольше ли, чем нужно (сейчас 1,34 с до последнего стежка, канва гаснет к 1,4 с).
- Плакат на 1440 / 1920 / 1024 / 390: птица не наезжает на заголовок, текст читается, кнопка не перекрыта.
- Стежок против сплошной обводки: сплошной тонкий контур с канвой читался как чертёж, пунктир — как вышивка; оставлен пунктир.
- Канва — прямоугольный кусок с жёстким краем (на 6 % виден только во время шитья): нужен ли мягкий край — вопрос дизайну.
- Фокус-кольцо пунктиром (Tab по шапке, кнопке hero, полям формы).
- Анимируются только `stroke-dashoffset` (в маске), `fill-opacity` и `opacity`; layout не трогается.

## Откат
Папка `exp/embroidered-hero/` удаляется целиком, корень сайта не менялся.
