# Эксперимент: next-case

**Идея:** «Следующее изделие». Сейчас каждый из 7 кейсов кончается тупиком: после последней картинки сразу форма. Здесь перед формой стоит финальный экран — следующий кейс портфолио. Это его карточка с главной, выросшая почти на весь экран: та же обложка, тот же фон, крупный заголовок, чипы. Обложка поднимается из-под нижнего края по мере дочитывания, текст проявляется. Весь блок — ссылка; под ним мелкой строкой «← Предыдущий: …» без обложки.
**Источник:** crazy (Безумец); приём предзагрузки — [GoogleChromeLabs/quicklink](https://github.com/GoogleChromeLabs/quicklink) (11.3k ⭐, Apache-2.0), повторён своим кодом, библиотека не вендорена.
**Цель:** портфолио читается подряд, как одна смена в цеху, без тупика перед формой; переход к следующему кейсу мгновенный, без белого кадра.

## Кольцо

Порядок — карточки секции `#projects` на главной **в порядке DOM**: сначала левая колонка сверху вниз, потом правая (на телефоне сетка схлопывается ровно в этот порядок):

ranepa → ncip-branding → dubai-real-estate → ourfish → region → pediatric → ncip-web → ranepa

## Что в блоке

- Подпись `Следующий проект` (капс, как `.caps`).
- Крупно ANS — `<h1>` следующего кейса: его человек первым увидит на следующей странице, так что переход читается без шва.
- Ниже — заголовок карточки с главной. Он нужен: у ncip-web и ncip-branding одинаковый h1 («Национальный центр исторической памяти при Президенте РФ»), различает их только заголовок карточки.
- Чипы карточки, обложка карточки (`/assets/img/index/*.webp`), фон карточки (`--card-bg` / `--card-grad`). Новых текстов нет.
- Обложка поставлена как на карточке главной: во всю ширину своей колонки (54% блока на десктопе, 100% на телефоне), низом к низу блока, прозрачный верх уходит за край.

## Движение

- CSS scroll-driven: именованный `view-timeline: --next` на блоке, обложке и тексту — `animation-timeline: --next`, диапазон `entry 0% → entry 100%` (доезжает до конца всегда, даже на коротком хвосте страницы).
- Обложка поднимается `transform: translateY(65%) → 0`, текст — `opacity 0 → 1` + сдвиг 40px. **Не clip-path:** clip-path по большой webp считается на main thread и даёт подлаг первого прохода (на него уже жаловались в прошлых экспериментах), transform и opacity композитятся на GPU.
- Базовые стили — конечное состояние, стартовое есть только в `from` кейфрейма. Поэтому в Firefox (scroll-driven нет), без `@supports (animation-timeline: view())` и при `prefers-reduced-motion: reduce` блок просто стоит готовый.
- Hover: обложка чуть растёт (`scale: 1.04`, отдельным свойством, чтобы не спорить с анимацией transform); ниже 1200 выключен, как у карточек главной.
- Ничего не липнет, колесо не перехватывается, номеров и прогресс-баров нет.

## Предзагрузка

`assets/next-case.js` (~25 строк, приём quicklink): IntersectionObserver на блоке (`rootMargin` 300px снизу) → в `requestIdleCallback` добавляет `<link rel=prefetch>` на страницу следующего кейса и на его первую картинку (`.pic` в шапке кейса, у неё `loading=lazy`, без префетча на приходе была бы вспышка). Срабатывает один раз; при `saveData` и 2g не грузит. `@view-transition` сознательно не включён: это тема эксперимента `view-transitions`, здесь «без белого кадра» дают префетч и paint holding браузера.

## Файлы

- `assets/next-case.css`, `assets/next-case.js` — подключены только к 7 страницам кейсов.
- В 7 `*/index.html` перед `#form` вставлен блок между комментариями `<!-- next-case:start/end -->`.
- Главная, политика и `styles.css` эксперимента не правились после `exp.py new`.

## Что проверять

- **Десктоп 1440:** дочитать любой кейс до конца — следующий кейс встаёт почти во весь экран под пилюлей шапки, обложка выезжает снизу, заголовок проявляется. Самые длинные заголовки — на `/pediatric/` (следующий — ncip-web) и `/ranepa/` (следующий — ncip-branding): текст не налезает на обложку. Клик — переход без белой вспышки, шапка нового кейса с картинкой сразу на месте.
- **Телефон 390:** блок в колонку — текст сверху, обложка во всю ширину снизу, без горизонтального скролла; «Предыдущий» под блоком.
- Firefox и reduced-motion: блок готовый, без движения.

## Откат
Папка `exp/next-case/` удаляется целиком, корень сайта не менялся.
