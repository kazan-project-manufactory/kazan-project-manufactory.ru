# Эксперимент: fabric-cards

**Идея:** «Карточки-ткань: ролик со станка». Секция «Наши проекты» переверстана как ткацкий цех: тёмный фон с переплетением, заголовок в два огромных слога (второй — контуром), горизонтальная лента-конвейер со scroll-snap. Каждый кейс — рулон на металлическом валу; полотно разматывается сверху вниз с наклоном по перспективе по мере того, как рулон въезжает в экран (непрерывно, по положению, а не «щёлк»). Пока полотно не размотано, поверх фото лежит диагональное переплетение; на hover оно проступает по краям. Крупные номера изделий 01–07, счётчик, стрелки, под лентой — нить с «челноком», показывающим, где мы в ленте. Плитки «ИИ-решений» — тот же приём, короче. Мануфактура буквально.
**Источник:** crazy (Безумец)
**Цель:** секция проектов перестаёт быть статичной сеткой и становится главным «жестом» страницы; посетитель листает кейсы как ленту и задерживается на них дольше.

## План
1. `tools/exp.py new fabric-cards` — копия сайта.
2. `index.html`: секция `#projects` → `.loom` (шапка с заголовком, счётчиком и стрелками; `ul.loom__track` из `li.roll` = вал + карточка + номер; `.loom__rail` с челноком). Тексты, ссылки, картинки, чипы карточек — без изменений.
3. `styles.css` (хвост): `@property --p` (0 — смотано, 1 — размотано), `clip-path: inset(0 0 calc((1 - var(--p))*100%) 0)` + `rotateX(calc((1 - var(--p))*-18deg))`, текстура `::after` с `opacity: calc(1 - var(--p))`, hover-маска по краям, лента `scroll-snap-type: x mandatory`, вал, номера, челнок. Скрытое состояние — только под `html.js`.
4. Скрипт в конце `index.html` (~35 строк): `--p` по горизонтальному положению рулона на `scroll`/`resize`; `IntersectionObserver` запускает первое разматывание с задержкой по индексу; колесо над лентой листает её (у края отдаёт скролл странице); стрелки — на соседний рулон; счётчик и челнок. Плитки ИИ — `.is-in` по IO.

## Что проверять
- При скролле к секции рулоны разматываются слева направо с задержкой ~110 мс; при листании ленты (колесо, стрелки, свайп) новые рулоны разматываются по мере въезда.
- Переплетение видно на несмотанном полотне и гаснет; при наведении проступает по краям.
- Счётчик и челнок следуют за лентой; стрелки шагают ровно на один рулон.
- Без JS и при `prefers-reduced-motion: reduce` — все карточки видны сразу, лента просто скроллится.
- 390: заголовок/счётчик/стрелки в столбик, рулон 82vw, свайп со snap. 1440: рулон 640px, три в кадре.
- Консоль без ошибок (проверено Playwright на обоих размерах).

## Что урезано
- Эффект только на главной; внутренние страницы — как в оригинале.
- Текстура ткани — CSS-градиенты, не изображение; «станок» — только вал и челнок.
- Нет drag-скролла мышью (колесо, стрелки, тач); нет клавиатурной навигации по ленте кроме tab по карточкам.
- `@property` (транзишен `--p`) — в Firefox < 128 разматывание будет без сглаживания, но всё видно.

## Откат
Папка `exp/fabric-cards/` удаляется целиком, корень сайта не менялся.
