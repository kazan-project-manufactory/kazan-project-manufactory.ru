# Эксперимент: bird-index

**Идея:** «Птица из семи работ». Птица в `assets/hero.svg` собрана ровно из 7 `<path>`, кейсов на сайте тоже 7. Футер становится оглавлением портфолио: каждая ступень птицы — ссылка на один кейс. Мануфактура собрана из своих работ.
**Источник:** crazy (Безумец).
**Цель:** проверить, может ли знак бренда нести смысл, а не только украшать.

## Что сделано
- Футер на всех страницах эксперимента (главная, 7 кейсов, политика) вырос из тонкой полосы в блок на ink-фоне: слева белая птица высотой 260 px, справа список из 7 кейсов. Строка логотипа, ссылки на политику и © осталась внизу как была.
- Каждый path птицы обёрнут в `<a>` с `aria-label` — заголовком карточки кейса с главной. Список справа — те же 7 ссылок текстом: заголовок карточки и её чипы, тексты один в один с карточек.
- Наведение или фокус на ступень: ступень и её строка в списке белые, остальные уходят в 25 % за 200 мс. Работает и обратно: наведение на строку подсвечивает ступень. Чистый CSS (`:has()`, `:hover`, `:focus-visible`), JS нет. При `prefers-reduced-motion` переход отключён.
- На странице кейса текущий кейс отмечен `aria-current="page"` (ступень и строка): его ступень белая, остальные 70 %, строка белая. На главной птица целиком белая.
- На телефоне (≤ 639) птица — маленький статичный знак над списком, работает список.
- Анимации появления нет.

## Ступень → кейс
По порядку карточек в разметке секции `#projects` главной (так они идут в `index.html`; на экране это две колонки, левая сверху вниз, потом правая), path по порядку в `hero.svg`:

| path | что в птице | кейс |
|---|---|---|
| 1 | нижний уступ над основанием | РАНХиГС, навигация по кампусу |
| 2 | основание | НЦИП, логотип и фирменный стиль |
| 3 | большая диагональ | Сайт агентства недвижимости в Дубае |
| 4 | нижняя полоса крыла | Портал о рыбной продукции |
| 5 | средние полосы крыла | Портал для жителей региона |
| 6 | голова и верх крыла | Сайт педиатрического университета |
| 7 | звезда над головой | Портал НЦИП |

## Что смотреть команде
- **Десктоп:** проскроллить любую страницу до футера, провести курсором по птице снизу вверх, потом по списку. Читается ли птица как оглавление, или это всё ещё картинка. Открыть кейс из птицы — на странице кейса его ступень отмечена.
- **Клавиатура:** Tab по футеру: сначала 7 ступеней, потом 7 строк списка (14 остановок — цена того, что ступени тоже ссылки).
- **Телефон:** птица маленьким знаком, ниже список с чипами. Самый длинный заголовок — НЦИП, брендинг.
- Без `:has()` (старые браузеры) ступени всё равно подсвечиваются при наведении на них самих, отваливается только связка со списком.
