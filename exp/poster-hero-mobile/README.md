# Эксперимент: poster-hero-mobile

**Идея:** первый экран телефона — плакат. Заголовок hero набран самым крупным кеглем, при котором самое длинное слово «ПРОФЕССИОНАЛЬНЫЕ» встаёт в строку, переносы поставлены руками, перечень и кнопка опущены к низу экрана, между ними — птица из десктопного hero, крупно и с обрезом по правому краю.
**Источник:** GitHub [chenglou/pretext](https://github.com/chenglou/pretext) (50.8k ⭐, MIT) — как инструмент замера при разработке, в страницу не подключается.
**Цель:** мобильный первый экран звучит так же статно, как десктопный.

## Что сделано
- Только главная, только ширины 320–959. Десктоп ≥960 не изменился: попиксельное сравнение с корнем на 1440/1024/960 отличается только бейджем эксперимента.
- Заголовок: `font-size: 6.658cqi`, то есть ширина колонки × 0.98 / 14.718 em. Кегли: 320 → 20.2, 360 → 22.9, 375 → 23.9, 390 → 24.9, 414 → 26.5, 430 → 27.5, 480 → 30.8, 640 → 39.9, 768 → 48.4, 959 → 61.1 px (было 20 / 20 / 20 / 20 / 30 / 30 / 30 / 30 / 36 / 36). Межстрочный — 1.06 вместо 1.2. Потолок `12svh` — для телефона в горизонтальном положении.
- Переносы на всех ширинах одни и те же (и совпадают с десктопом): ПРОФЕССИОНАЛЬНЫЕ / ИНТЕРНЕТ РЕШЕНИЯ / ДЛЯ ГОСУДАРСТВА / И БИЗНЕСА. В разметке добавлен один неразрывный пробел — `интернет&nbsp;решения` (`для&nbsp;государства` и `и&nbsp;бизнеса` уже были); pretext подтвердил, что обычный перенос даёт ровно эти четыре строки на всех десяти ширинах.
- Перечень: тексты и порядок прежние; тише — 13–14px, белый 82 %, иконка 12px. Кегль на телефоне — `min(13px, …)`: самый длинный пункт «ОБРАЗОВАТЕЛЬНЫЕ ПЛАТФОРМЫ» (22.267 em) встаёт в одну строку даже на 320 (в оригинале он там переносится).
- Hero высотой в экран (`min-height: 100svh`): заголовок сверху, перечень и кнопка снизу, кнопка в первом экране на 320×568, 390×664, 390×844, 430×932 и 768×1024.
- Птица (та же SVG, что на десктопе) занимает свободное поле между заголовком и перечнем и обрезана краем экрана на 22 %. Если поле ниже 180px (320×568, 390×664, планшет в горизонтальном положении), птица не показывается — это решает container query по высоте поля.
- Без JS в странице, без CDN, без анимаций.

## Замер
`tools/measure.html` загружает ANS, меряет строки через pretext (`prepareWithSegments` + `measureNaturalWidth`, проверка `measureLineStats`/`walkLineRanges`) и сверяет с шириной DOM-span (совпадает до 0.1px). Запуск:
`PW=<путь к node_modules/playwright> node tools/measure.mjs` (параметры: `ls=` трекинг в em, `safe=` запас, `lines=` строки через `|`).
`tools/shots.mjs` снимает один экран после загрузки шрифтов и печатает кегль, число строк, низ кнопки и наличие горизонтального скролла.
pretext лежит в `tools/vendor/pretext/` (dist + LICENSE, 480 КБ, MIT).

## Что проверять
- Только телефон и планшет: 320, 360, 390, 430, 768. Самое длинное слово занимает строку от края до края, Д не задевает строку ниже, кнопка в первом экране.

## Чего не даёт
- На 320 кегль почти не вырос (20.2 против 20): «ПРОФЕССИОНАЛЬНЫЕ» в ANS — 14.7 em, шире не встать. Плакатность на телефоне держится на композиции, межстрочном и тишине перечня; заметный рост кегля — с 414 и на планшетах.

## Откат
Папка `exp/poster-hero-mobile/` удаляется целиком, корень сайта не менялся.
