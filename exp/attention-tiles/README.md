# Эксперимент: attention-tiles

**Идея:** секция «ИИ-решения» перестаёт быть списком плиток с эмодзи и становится картой внимания. Пять задач — узлы графа; слева от них подписанные источники данных, справа — наши кейсы. Наводишь на задачу — видишь, на чём она работает и где мы её уже сделали. Толщина и яркость связи = её вес для задачи: это и есть визуальная метафора внимания.
**Источник:** доведённая версия отклонённого `neural-ai` (там были абстрактные частицы без смысла; здесь каждый узел подписан, каждая связь ведёт в конкретный кейс).
**Цель:** посетитель на главной за один взгляд понимает, что ИИ у нас — не список модных слов, а связка «данные → задача → сданный проект», и уходит с главной в кейс, а не в форму вслепую.

## Как устроено

- Разметка — обычный CSS-grid: три колонки (`Данные` / `Задачи` / `Наши кейсы`). Никаких координат в коде.
- Рёбра лежат в самой разметке: у каждой плитки `data-in="d-docs:.9,…"` и `data-out="c-ncip:.9,…"` — id узла и вес 0…1. Один источник правды, правится руками без пересборки.
- `attention.js` измеряет реальные DOM-узлы (`getBoundingClientRect`) и рисует кривые Безье в `<svg>` под колонками. Раскладку считает браузер, скрипт только соединяет.
- Вес → `opacity` и `stroke-width`. В покое `0.05 + 0.14·w`, у выбранной задачи `0.18 + 0.5·w`, у остальных 0.04.
- В покое по графу идёт медленная волна: одна задача за раз (4.8 с на задачу), внутри — сдвиг фазы «данные → задача → кейс». Узлы едва заметно дышат (CSS, opacity 0.26→0.58).

## Что проверять

- Скролл: колесо и тач работают ровно как на остальной странице — перехвата нет ни в секции, ни над SVG (`pointer-events: none`).
- Покой: волна читается как «дыхание», а не как мигание. Смотреть 20–30 секунд, не должно раздражать.
- Наведение на плитку: толстые линии идут к тому, что для задачи действительно главное; остальное почти пропадает.
- Клик по плитке фиксирует выбор (`aria-pressed`), повторный клик и Escape снимают.
- Клавиатура: Tab проходит задачи → данные → кейсы, фокус на задаче подсвечивает её связи, у каждого кейса видна ссылка «Смотреть кейс».
- 960px и 640px: на узком связи не превращаются в кашу — колонки становятся списком, тап по задаче подсвечивает её данные и кейсы (вес виден кольцом вокруг точки).
- `prefers-reduced-motion: reduce` в системе: анимации нет, но граф нарисован и веса читаются; наведение работает.
- Секция вне экрана: в Performance нет кадров rAF (проверить `IntersectionObserver`, rootMargin 160px).
- Без JS (`attention.js` отключить): три подписанных списка, ссылки на кейсы кликабельны, пустого канваса нет.
- Целостность графа: `python3 -c` по `index.html` — все id из `data-in/data-out` существуют, веса в (0;1], нет висячих узлов. Сейчас 31 ребро, 5 задач, 5 источников, 6 кейсов.
