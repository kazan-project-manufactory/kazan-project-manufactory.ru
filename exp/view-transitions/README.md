# Эксперимент: view-transitions

**Идея:** клик по карточке проекта на главной — карточка «раскрывается» в обложку на весь первый экран страницы кейса, остальная страница мягко crossfade'ится, логотип и шапка стоят на месте. Между обычными статическими страницами, ноль JS — только CSS. Сама страница кейса пересобрана под эту драматургию: обложка на весь экран с заголовком поверх, компактная фиксированная пилюля-шапка, редакционный ритм текста (заголовок раздела слева и липнет, текст справа), картинки выходят за текстовую сетку.
**Источник:** https://github.com/WICG/view-transitions (850 ⭐) — cross-document view transitions.
**Цель:** переход главная → кейс ощущается как раскрытие карточки в обложку, а не как перезагрузка; кейс читается как лонгрид, а не как стопка одинаковых блоков.

## План
1. `@view-transition { navigation: auto; }` в `styles.css` эксперимента — включает cross-document переходы на всех страницах.
2. Главная: каждой `a.card` по `href` — `view-transition-name: case-<slug>` (селектор `a.card[href$="/<slug>/"]`). Разметка главной не менялась.
3. Кейсы (все 7) пересобраны скриптом из оригиналов: `<section class="cover">` (первая картинка кейса = `img.cover__img` с `view-transition-name:case-<slug>`, `loading="eager" fetchpriority="high"`; поверх — чипы с карточки главной, H1, лид), затем `<article class="story">`: блоки `story__block` (H2 + абзацы, сетка 4/8) и `figure.fig` — `fig--bleed` (во всю ширину окна), `fig--wide` (1400) чередуются, `fig--pair` (две картинки со сдвигом второй). Блок «Результат» — `section.result` на брендовом градиенте. Форма, футер, бейдж — как в оригинале.
4. `.header .logo`/`.pill .logo` → `logo`, `.header .nav`/`.pill .nav` → `nav` (футерный логотип не именуем — дубликат имени отменил бы переход).
5. `root` — crossfade .35s; `case-*` — .5s ease, `object-fit: cover; height: 100%` у old/new, чтобы морф карточки 3:4 в обложку 16:9+ не растягивал снимок.
6. `prefers-reduced-motion: reduce` — все анимации перехода `none`.

## Что проверять
- Chrome 126+ / Edge 126+, Safari 18.2+: клик по карточке → карточка растягивается в полноэкранную обложку, остальное — crossfade; «назад» — обратный морф. Firefox: эффекта нет, обычная навигация.
- Логотип: на главной он в `.header`, на кейсе — в компактной `.pill` (меньше и в другой точке) — должен доехать и уменьшиться, а не мигать. Если дёргает — убрать имя `nav`, оставить только `logo`.
- Мобильный (390): `.nav` скрыт на обеих страницах — переход только `logo` + `case-*`; обложка `100svh`, длинные заголовки (`cover__title--long`) не вылезают под пилюлю; горизонтального скролла нет.
- Все 7 кейсов: `ranepa`, `ncip-branding`, `ncip-web`, `ourfish`, `pediatric`, `region`, `dubai-real-estate`. Тексты, картинки, порядок — как в оригинале, только перегруппированы. `privacypolicy` не участвует.
- Читаемость заголовка поверх обложки на светлых картинках (pediatric, ncip-web) — держит градиентная подложка снизу; если мало, усилить `.cover::after`.
- Локальная проверка: `vt-check.mjs` / `vt-all.mjs` (Playwright): `document.startViewTransition` есть, computed `view-transition-name` на карточке и на обложке совпадают для всех 7, консоль без ошибок, `history.back()` возвращает на главную, `scrollWidth` не шире окна на 1440 и 390.

## Что урезано
- Нет JS-навигации (`navigation` API / prefetch): кросс-документный переход работает только там, где браузер сам его поддерживает.
- Именованы только обложка, логотип и nav — заголовок кейса и чипы не морфятся из карточки (у карточки и обложки разная типографика, морф текста выглядел бы как мазня).
- Направление (вперёд/назад) не различается, анимации симметричны.
- Пересборка кейсов — механическая (скрипт `rebuild-case.py` в scratchpad сессии): чередование bleed/wide идёт по порядку картинок, без ручной режиссуры под каждый кейс.

## Откат
Папка `exp/view-transitions/` удаляется целиком, корень сайта не менялся.
